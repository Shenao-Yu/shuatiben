# 刷题本

在本机刷面试题的小工具。题目来自三个开源仓库：

| 来源 | 用在哪里 |
|:--|:--|
| [JavaGuide](https://github.com/Snailclimb/JavaGuide) | 后端基础（网络、操作系统、MySQL、Redis、消息队列、分布式、高可用、Java 系列）和 AI 应用开发文章 |
| [代码随想录](https://github.com/youngyangyang04/leetcode-master) | 力扣题，按专题排好顺序，带题解和多语言代码 |
| [AgentGuide](https://github.com/adongwanai/AgentGuide) | 大模型、RAG、Agent 面试题库和备战手册 |

## 启动

需要 Python 3.8+ 和 git，不用装任何依赖。

```bash
git clone https://github.com/Shenao-Yu/shuatiben.git
cd shuatiben
python3 app.py
```

仓库里只有工具代码，不包含任何题目内容；题库是在你本机从上面三个仓库下载后生成的。

- 第一次启动会从 GitHub 下载内容并生成题库，大约 20 秒；之后直接打开。
- 浏览器会自动打开 `http://127.0.0.1:8765`，端口被占用时会自动换一个，以终端里打印的地址为准。
- 按 `Ctrl+C` 退出。

想拉取三个仓库的最新内容：

```bash
python3 app.py --update
```

## 怎么刷

1. 左侧选一个分组，点「开始刷题」（会从第一道没刷过的题开始）。
2. 先自己回答，可以把要点写进「我的回答 / 笔记」，再按 **空格** 看答案。
3. 按 **1 不会 / 2 模糊 / 3 掌握** 打分，自动进入下一题。

其他快捷键：`←` `→` 切题，`F` 收藏，`Esc` 回列表，`/` 搜索。

- **待复习**：所有标了「不会」「模糊」的题，不会的排前面，越久没复习越靠前。
- **无参考答案**：AgentGuide 的部分真题只有题目，这类题会标出来，并提供「搜索相关内容」按钮，去题库里找相关讲解。
- **力扣题**：题解自带 C++ 代码，在答案右上角或设置里选其他语言，会在后面追加对应版本。
- **设置**：可以切换深浅色、隐藏用不到的分组（比如不准备 Java 就关掉 Java 相关的分组），以及导出 / 导入进度。

## 数据放在哪里

| 路径 | 内容 |
|:--|:--|
| `data/progress.json` | 刷题进度、笔记、收藏 |
| `data/backups/` | 每天第一次保存时自动备份一份，保留 14 天 |
| `data/bank.json` | 生成的题库 |
| `.cache/` | 三个仓库的本地副本，删掉后下次启动会重新下载 |

## 调整题库

`build.py` 顶部的 `BANKS` 列出了每个分组用到的文件，增删后重新运行 `python3 app.py --update` 即可。
